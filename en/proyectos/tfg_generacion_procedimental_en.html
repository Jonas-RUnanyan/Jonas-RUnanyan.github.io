The project

Bachelor's Thesis (Computer Science Engineering, UPM) in which I designed and built, from scratch, a system that generates complete cities in Minecraft, in the context of the Generative Design in Minecraft Competition (GDMC): an international contest requiring 100% autonomous settlement generation, judged by a panel of experts in modding, AI, architecture, and urban planning. My approach investigates what happens when, instead of removing the human from the process, you actively bring them into the evolutionary loop through an interactive genetic algorithm (IGA) that uses the user as the fitness function for the hardest criterion to formalize in the competition: aesthetics.

The system

The system takes an unknown terrain and the number of buildings to construct as input, and generates the complete city by combining several modules. All the design, research, and code are individual work.

Terrain and plots
I analyzed the terrain through the GDMC-HTTP API to build height, slope, and block-type maps, and designed a genetic algorithm that places building plots by optimizing a custom fitness function that penalizes slope, water presence, and elongated plots, while rewarding larger, more square-shaped ones.

Shape grammar and indirect parametric encoding
I extended an existing box-split shape grammar engine from the literature, adding a full 90/180/270° rotation system propagated to every child node, plus logical operators (AND/OR) and comparators for rule constraints — capabilities the original system didn't support. I also designed a custom indirect parametric encoding (IPE): a 51-dimension vector that represents color, material, category, and finish of each block in a continuous latent space, with spatial variation through noise and periodic patterns, projected back onto the discrete block vocabulary via weighted nearest-neighbor search. This makes it possible to generate coherent material palettes for an entire city from a small genome, instead of having to optimize each block directly.

Interactive genetic algorithm (IGA)
I built a tournament interface where the system raises two candidate cities over the same plot layout and the user picks the one they prefer. I designed the algorithm to alternate generations with human feedback, "contamination" generations that inject random diversity, and autonomous local-exploration generations with elitism — a scheme specifically designed to minimize the number of decisions asked of the user without losing search capability.

Road network
I implemented a two-phase hybrid approach to connect all buildings: ACO-Steiner (ant colony optimization over the rectilinear Steiner tree) decides the network topology, using a cost function I modified to also penalize terrain elevation changes rather than just distance; and A* then resolves each individual connection while avoiding obstacles and water.

User validation

I designed and ran an experiment with 5 users: each one generated a city using the IGA, and afterward everyone blind-rated those cities together with 5 more generated at random, without knowing which was which.

IGA-generated cities scored an average aesthetic rating of 7.30/10 versus 6.84/10 for the random group, with a medium effect size (Cohen's d ≈ 0.60) despite not reaching statistical significance with only 5 evaluators. Functionality and adaptability remained equivalent between both groups, confirming that optimizing for aesthetics didn't come at the expense of other criteria. The most consistent finding across debrief interviews was that color — specifically color harmony between buildings — was by far the strongest driver of users' aesthetic perception. The experiment also made evaluator fatigue clearly visible: decision times grew increasingly irregular from one generation to the next.

Scientific publication

Building on this thesis, I wrote and submitted a paper to the IEEE Conference on Games (CoG), formalizing the system and strengthening the experiment's statistical analysis (including the effect-size calculation). The paper wasn't accepted this round, but it was a valuable experience in formal scientific writing, peer review, and communicating research results beyond the university's own academic context.

What I took away

  • Designing and implementing a complete interactive genetic algorithm, from the genome to the user feedback interface.
  • Extending an existing shape grammar engine by adding full four-direction rotation and logical operators to rule constraints.
  • Designing a custom indirect parametric encoding (51-dimension latent space) to generate coherent material palettes.
  • Applying ant colony optimization (ACO-Steiner) and A* to slope-aware urban path network planning.
  • Designing and running a user study and analyzing results with statistical rigor (Welch's t-test, Cohen's effect size).
  • Writing and submitting a paper to an IEEE conference based on an academic project.
